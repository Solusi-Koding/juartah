Kebijakan Privasi

Berlaku sejak 24 November 2026

Halaman ini menjelaskan data apa yang dikumpulkan oleh layanan kirim file di juartah.my.id, untuk apa data itu dipakai, dan berapa lama disimpan. Layanan ini dijalankan oleh Juartah Printing, toko percetakan di Shopee.

Data dari pelanggan

Pelanggan tidak perlu membuat akun. Yang kami terima hanya:

  • Nomor pesanan Shopee.
  • File desain yang dikirim, beserta nama, ukuran, dan jenis filenya.
  • Catatan yang ditulis pelanggan, untuk seluruh pesanan maupun per file.
  • Waktu pengiriman.
  • Alamat IP, hanya untuk membatasi permintaan berlebihan dan mencegah penyalahgunaan. Tidak disimpan bersama pesanan.

Kami tidak meminta nama, nomor HP, alamat, password, OTP, atau data pembayaran di halaman ini.

Untuk apa data dipakai

Data hanya dipakai untuk mencetak pesanan: mencocokkan file dengan pesanan Shopee, memeriksa file, memberi tahu pelanggan bila file perlu diperbaiki, dan menampilkan status pesanan. Data tidak dijual, tidak dipakai untuk iklan, dan tidak dibagikan ke pihak lain selain penyedia layanan yang disebut di bawah.

Siapa pun yang mengetahui nomor pesanan dapat melihat status pesanan, pesan revisi dari toko, dan jumlah file, serta dapat menambah file. Nama dan isi file tidak pernah ditampilkan di halaman publik.

Data akun Google

Login dengan Google hanya dipakai oleh pemilik dan staf toko, bukan oleh pelanggan.

  • Email Google pemilik dan staf dipakai untuk memeriksa apakah orang tersebut berhak membuka dashboard toko.
  • Akses Google Drive hanya diminta dari akun pemilik toko, dengan izin drive.file. Izin ini hanya memberi akses ke file dan folder yang dibuat oleh aplikasi ini, yaitu file kiriman pelanggan. File lain di Drive pemilik tidak bisa dilihat oleh aplikasi.

Data dari Google tidak dipindahkan ke pihak lain, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model kecerdasan buatan. Penggunaan dan pemindahan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Tempat penyimpanan

  • File desain disimpan di Google Drive milik Juartah Printing.
  • Nomor pesanan, catatan, status, dan daftar file disimpan di database Cloudflare.
  • Halaman ini dijalankan di Cloudflare, yang juga memproses alamat IP untuk keamanan. Pemeriksaan anti-bot Cloudflare Turnstile dapat dipakai saat mengirim file.

Akses Google Drive disimpan dalam bentuk terenkripsi.

Lama penyimpanan

  • File dan catatan disimpan sampai pesanan selesai dan dihapus oleh toko. Toko dapat mengatur agar file pesanan selesai dipindah ke Trash Google Drive secara otomatis, lalu Google menghapusnya permanen setelah 30 hari.
  • Upload yang tidak selesai dibersihkan setelah sekitar 8 hari.
  • Sesi login pemilik dan staf berakhir setelah 30 hari.

Cookie

Pelanggan tidak diberi cookie oleh kami. Pemilik dan staf diberi satu cookie login agar tetap masuk. Cloudflare Turnstile dapat memakai cookie sendiri untuk pemeriksaan anti-bot.

Hak Anda

Anda dapat meminta file dan catatan pesanan Anda dihapus lebih cepat, atau menanyakan data yang kami simpan. Hubungi Juartah Printing lewat chat toko di Shopee dan sebutkan nomor pesanan Anda.

Pemilik toko dapat mencabut akses aplikasi ke Google Drive kapan saja di pengaturan akun Google.

Perubahan

Bila kebijakan ini berubah, tanggal di bagian atas halaman ikut diperbarui.
